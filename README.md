# Experiment 7: Adaptive UI using ListView and ImageView

## Aim
To create an adaptive Android user interface using ListView and ImageView.

## Description
This Android application demonstrates an adaptive UI using a ListView. Each list item contains an ImageView, title, and description.

## Technologies Used
- Android Studio
- Java
- XML
- ListView
- ImageView
- Custom Adapter

## Features
- Scrollable ListView
- Image display using ImageView
- Custom list item layout
- Adaptive layout using match_parent, wrap_content and layout_weight
- CustomAdapter using BaseAdapter

## Project Structure

- `MainActivity.java` - Main application logic
- `CustomAdapter.java` - Connects data with ListView
- `activity_main.xml` - Main screen layout
- `list_item.xml` - Individual list item layout

## Output
The application displays a scrollable list containing images, titles, and descriptions.

## Result
Successfully created an adaptive Android UI using ListView and ImageView.
